### 防抖：多次触发，只执行最后一次

当事件被触发后，延迟n秒后再执行回调，如果在这n秒内又被触发，则重新计时

```js
function debounce(fn, wait) {
  let timer = null
  return function () {
    clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, arguments)
    }, wait);
  }
}
```

### 节流：规定时间内只执行一次

```js
function throttle(func, delay) {
  var timer = null
  return function () {
    var context = this
    var args = arguments
    if (!timer) {
      timer = setTimeout(() => {
        func.apply(context, args)
        timer = null
      }, delay);
    }
  }
}

function handle() {
  console.log(Math.random())
}

window.addEventListener('scroll', throttle(handle, 1000))
```
