## JSON.parse(JSON.stringify(obj))

JSON.stringify() 只能处理基本的对象、数组、原始类型。日期会被转成字符串，Set 会被转成 {}，函数、undefined、Symbol 会被忽略。

```js
const obj = {
  number: 1,
  bool: false,
  symbol: Symbol('obj'),
  date: new Date(),
  func: () => {},
  set: new Set([1, 2, 3]),
  map: new Map([[1, 2]]),
  error: new Error('error'),
  regex: /foo/,
  deep: {
    e: undefined,
    f: null,
  },
};
```

```js
const newObj = JSON.parse(JSON.stringify(obj));

console.log(newObj);
// {
//   number: 1,
//   bool: false,
//   date: '2023-12-05T09:52:32.816Z',
//   set: {},
//   map: {},
//   error: {},
//   regex: {},
//   deep: { f: null },
// }
```

## structuredClone

- 无限嵌套的对象和数组
- 循环引用
- undefined、Date、Map、Set、Error、RegExp
- Blob、File、ImageData、ArrayBuffer...

```js
const obj = {
  number: 1,
  bool: false,
  date: new Date(),
  set: new Set([1, 2, 3]),
  map: new Map([[1, 2]]),
  error: new Error('error'),
  regex: /foo/,
  deep: {
    e: undefined,
    f: null,
  },
};

obj.deep.obj = obj;
```

### structuredClone 不能克隆

- 函数
- DOM 节点
- 属性描述符、设置器和获取器
- 对象原型

函数和 DOM 节点都抛出 DataCloneError 异常

```js
const obj = {
  func: () => {},
  el: document.body,
};
```

```js
const obj = {
  get a() {
    return 1;
  },
};

window.structuredClone(obj);
// {a: 1}
```

不会遍历或复制原型链，如果克隆一个 class 实例，克隆的对象不再被识别为这个 class 实例，但这个类的所有有效属性将被克隆

```js
class MyClass {
  a = 1;
  func() {}
}

const myClass = new MyClass();

const clone = structuredClone(myClass);
// {a: 1}

clone instanceof MyClass; // false
```
