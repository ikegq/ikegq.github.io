## v-for 和 v-if

- 在 vue2 中，v-for 优先级高于 v-if
- 在 vue3 中，v-if 优先级高于 v-for，所以 当 v-if 执行时，调用的变量还不存在，就会导致异常

在外层嵌套 template(页面渲染不生成 dom 节点)，在 template 中进行 v-if 判断，在内部进行 v-for 循环；使用 computed 计算属性提前过滤掉不需要显示的项

### 插值、v-html、v-text、v-pre

```vue
<script setup>
const desc = '<h3>标题</h3>';
</script>

<template>
  <div>{{ desc }}</div>
  <div v-html="desc"></div>
  <div v-text="desc"></div>
  <div v-pre>{{ desc }}</div>
</template>
```

<script setup>
  const desc = '<h3>标题</h3>'
</script>

- 插值

<div>{{ desc }}</div>

- v-html 设置标签的 innerHTML

<div v-html="desc"></div>

- v-text 设置标签的文本值

<div v-text="desc"></div>

- v-pre 跳过这个元素及其所有子元素的编译过程，可以利用 v-pre 跳过没有使用指令语法、没有使用插值语法的节点，加快编译

<div v-pre>{{ desc }}</div>

### v-cloak

v-cloak 指令通常与 css 配合使用，用于在 vue 实例加载和编译之前隐藏元素，通过给元素添加 v-cloak 属性，然后在 css 中定义对应的样式，可以确保在 vue 实例加载完成前，该元素的内容不会显示在页面上

```vue
<template>
  <div v-cloak>{{ num }}</div>
</template>

<style scoped>
[v-cloak] {
  display: none;
}
</style>
```

### v-once

v-once 仅渲染元素和组件一次，并跳过之后的更新

### v-memo

vue3.2 新增的性能优化的指令

> 缓存一个模板的子树，在元素和组件上都可以使用。为了实现缓存，该指令需要传人一个固定长度的依赖值数组进行比较。如果数组里的每个值都与最后一次的渲染相同，那么整个子树的更新将被跳过

```vue
<div v-memo="[valueA, valueB]">
  如果值未更改，就不重新渲染
</div>
```

当组件重新渲染，如果 valueA 和 valueB 都保持不变，div 及其子项的所有更新都将被跳过，实际上，甚至虚拟 DOM 的 vnode 创建也将被跳过，因为缓存的子树副本可以被重新使用。

v-memo 传入空数组(v-memo="[]")将与 v-once 效果相同
