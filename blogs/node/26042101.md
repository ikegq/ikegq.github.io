## type

Node.js 默认把 .js 文件作为 CommonJS 模块来处理(使用 require() 和 module.exports)，但一旦在项目根目录 package.json 中设置了：

- "type": "module"，则 所有本包下的 .js 文件作为 ES 模块来处理(使用 import 和 export)，require() 会报错(除非用 createRequire)
- "type": "commonjs"，显示声明按 CommonJS 模块来处理
- 不写 "type" 或设为其他值，则默认按 CommonJS 模块来处理

## main

commonjs 引入方式的程序入口文件，当一个模块被 require('module') 引入时，Node.js 会查找该模块的 package.json 文件中的 main 字段，然后加载该字段指定的文件。如果未设置 main 字段，Node.js 会默认尝试加载模块根目录下的 index.js 文件。

```json
{
  "main": "./src/index.js"
}
```
