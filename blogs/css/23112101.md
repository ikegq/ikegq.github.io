## CSS 自定义属性 @property

css 内定义写法

```css
@property --pie {
  syntax: '<percentage>';
  inherits: false;
  initial-value: 25%;
}
```

Javascript 内定义写法

```js
CSS.registerProperty({
  name: '--pie',
  syntax: '<percentage>',
  inherits: false,
  initialValue: '25%',
});
```

- @property --property-name 自定义属性名称，定义后可在 css 中通过 var(--property-name)使用
- syntax 必需，该自定义属性的类型规则
- inherits 必需，是否允许继承
- initial-value 初始值

- length 长度值，px、em、vw
- number 数字值
- percentage 百分比
- length-percentage 长度或百分比值，或 calc()
- color 颜色值
- image 图像值，url()引入的图像，gradient 渐变图像
- url
- integer 整数值
- angle 角度值 360deg、400grad、1turn、1rad
- time 时间值 1s、200ms
- resolution 分辨率，dpi、
- transform-list 变换函数值，matrix()、translate()、scale()、rotate()、skew()等
- custom-ident ident 值，ease、linear 等

### linear-gradient 渐变背景过渡

```html
<div class="box"></div>
```

```css
@property --color {
  syntax: '<color>';
  inherits: false;
  initial-value: #fff;
}

.box {
  --color: #c0ffee;
  background: linear-gradient(to right, #fff, var(--color));
  transition: --color 1s ease-in-out;

  width: 300px;
  height: 40px;

  &:hover {
    --color: #b4d455;
  }
}
```

### conic-gradient 角度渐变

```html
<div class="pie"></div>
```

```css
@property --pie {
  syntax: '<percentage>';
  inherits: false;
  initial-value: 25%;
}

.pie {
  --pie: 25%;
  background: conic-gradient(yellowgreen var(--pie), transparent var(--pie));
  transition: --pie 300ms ease-in-out;

  width: 300px;
  height: 300px;
  border-radius: 50%;

  &:hover {
    --pie: 60%;
  }
}
```

### text-underline-offset 文字下划线偏移

```html
<span class="text">text underline</span>
```

```css
@property --offset {
  syntax: '<length>';
  inherits: false;
  initial-value: 0;
}

.text {
  text-underline-offset: var(--offset);
  text-decoration-line: underline;
  text-decoration-color: transparent;
  transition: --offset 300ms, text-decoration-color 300ms;

  &:hover {
    --offset: 10px;
    text-decoration-color: orange;
  }
}
```
